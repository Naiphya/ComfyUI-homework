# 5.個人心得

我沒有很喜歡這種 還是偏好本地下載模型來玩 <br>喜歡去reddit等論壇找終端指令來用 而不是用這種軟體<br>

而且這種依賴本地運算的軟體看起來很臃腫肥大 光是前置佈署就下載很久<br>

再說本地運算本來就有劣勢 我目前外出帶的筆電ram跟vram都沒那麼高可用 <br>正常都得使用一定規格桌機跑了<br>

甚至很多人是普通商業iGPU筆電<br>



如果只能使用cpu執行這種生圖會等非常久<br>

遇到顯卡圖形驅動程式安裝錯誤或衝突機率很高<br>




而我如果真的非得使用ai工具生圖 <br>我依然會去找雲端商業模型或是看看有沒有新的Api可用 再整合到自己python code去作使用不然這種東西生出來會很糟
